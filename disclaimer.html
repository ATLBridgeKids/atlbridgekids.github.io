Privacy

What we share, and what we don't

Short version: signup info stays private. The directory is the only place info is shared, and only with permission.

Event sign-ups

When you sign up for an event, the info you enter — participant name, age, graduation year, and any contact details you provide — is saved to a private Google Sheet that only the instructor (Andre) can see. It is used only to run that event, take attendance, and reach you if the event changes.

The public event pages show only aggregate numbers: how many kids have signed up, broken down by grade. No names, emails, or phone numbers ever appear on this website from event sign-ups.

The directory

The directory is a separate, opt-in list. It exists so families who want to connect with other bridge families in Atlanta can find each other. You are only listed if you explicitly check the "share with directory" box on the directory form. You can ask to be removed at any time by emailing the instructor.

What appears in the directory: parent name, kid's first name, current grade (calculated from graduation year), school, and whatever contact info you chose to include.

Grade level

We ask for graduation year rather than current grade so that the site can display up-to-date grade levels without you needing to re-enter them each year. Grade is calculated automatically each fall.

Payments and donations

Donations go through third-party services (Venmo, PayPal, Zelle, etc.). This site never handles or stores payment information.

Photos and videos

Photos taken at events won't be posted on this website without asking families first.

Questions

Contact Andre through any event or directory form and I'll get back to you.
